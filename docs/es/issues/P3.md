## EPIC 10 — UI/UX y calidad de código

### 10.1 — Unificar los estados de candidato entre pantallas

**Problema:** dos vocabularios distintos, y ninguno coincide con el backend:

- `src/components/ui/StatusDropdown.jsx:9` → `["No contratado", "Contratado", "Contactar"]`
- `src/pages/AdvancedResults.tsx:8,92` → `["No Contratado", "Contactado", "Contratado"]`
- Enum real de la API (§5) → `DISPONIBLE | CONTRATADO`

Difieren en texto ("Contactar" vs "Contactado") y en casing ("No contratado" vs "No Contratado").

**Pasos:**

1. Definir un único set de labels (derivado del enum del backend) en un lugar compartido (ej. `src/types` o una constante).
2. Reemplazar los literales en `StatusDropdown.jsx` y `AdvancedResults.tsx`.
3. Alinear con la decisión de **P1 §6.3** (si el estado de candidato no persiste, ajustar el copy para que no implique guardado).

**✅ Criterio:** un único vocabulario de estados de candidato en toda la app.

### 10.2 — Ícono mostrar/ocultar contraseña invertido

**Archivo:** `src/components/ui/LoginForm.tsx` (~línea 60).

Hoy: contraseña visible → `Eye` (abierto); oculta → `EyeOff`. La convención habitual es la inversa (ojo abierto = "mostrar" cuando está oculta).

**Fix:**

```tsx
{showPassword ? <EyeOff className="w-5 h-5" /> : <Eye className="w-5 h-5" />}
```

**✅ Criterio:** ícono de contraseña con la convención correcta.

### 10.6 — Importar los tipos en vez de redeclararlos

`src/pages/EvaluationsHistory.tsx` define localmente la interfaz `EvaluationVacancy` (con el comentario "Declaramos la estructura aquí mismo para solucionar las líneas rojas de TypeScript"), cuando `src/types/evaluations.types.ts` ya la exporta idéntica. Importarla desde ahí.

**✅ Criterio:** un solo lugar de verdad por cada tipo.

---

### 10.7 — Dependencias muertas en `package.json`

`express`, `cors` y `dotenv` están declaradas como `dependencies` de un frontend 100 % cliente. También `react-router` junto a `react-router-dom` (que ya lo arrastra). Desinstalarlas reduce el árbol de dependencias y evita confusión sobre la arquitectura.

**✅ Criterio:** `package.json` refleja solo lo que el código importa.
